# Live Customer Support Chat

## Описание

**Live Customer Support Chat** — система онлайн-поддержки пользователей с обменом сообщениями в реальном времени, очередью обращений и интерфейсом для операторов.

Проект реализует полный цикл работы техподдержки: создание обращения клиентом, ожидание в очереди, подключение оператора, переписку, передачу чата и сохранение истории сообщений.

---

## Основные возможности

### Клиент
- Создание нового чата с поддержкой
- Отправка и получение сообщений в реальном времени
- Отображение статуса обращения:
    - `В очереди`
    - `Оператор подключился`
    - `Чат завершён`
- Просмотр списка своих обращений
- Повторный вход в ранее созданные чаты

---

### Оператор
- Авторизация (логин / пароль)
- Просмотр очереди обращений
- Принятие чатов из очереди
- Ведение нескольких чатов одновременно
- Передача чата другому оператору или отделу
- Завершение чата

---

### Очередь и сообщения
- Все новые чаты попадают в очередь ожидания
- Очередь работает по принципу **FIFO**
- Один чат может быть назначен только одному оператору
- Сообщения доставляются через **WebSocket**
- История сообщений сохраняется в базе данных
- При перезагрузке страницы история загружается из БД
- Поддержка reconnect без потери сообщений

---

## Пользовательские сценарии

### Клиент
Переходит на сайт → начинает чат → выбирает тему обращения → отправляет сообщение → ожидает оператора → общается с оператором → чат завершается → история сохраняется и доступна позже.

---

### Оператор
Авторизуется → просматривает очередь → принимает чат → решает вопрос или передаёт чат → завершает чат.
